# GGitar

**Windows 电吉他练习工作台**

GGitar 将声卡输入、效果器、吉他谱跟弹、原曲伴奏和指板训练整合在一个桌面应用中，适合日常练琴、分段练习和录音复盘。

[下载与版本记录](https://github.com/Gx-20hh/GGitar/releases) · [反馈问题](https://github.com/Gx-20hh/GGitar/issues) · [功能规划](docs/功能规划.md)

## 功能

| 模块 | 说明 |
| --- | --- |
| 实时音色 | 内置效果器链、音色预设、NAM 模型、箱体 IR、VST3 插件宿主 |
| 谱面跟弹 | 导入 Guitar Pro 3–8，滚动谱面、多轨混音、变速、A–B 循环和等待模式 |
| 弹奏反馈 | 基于干信号的音高与节奏判定、成绩卡、薄弱小节提示、延迟校准 |
| 我的曲库 | 本地文件夹扫描、搜索、收藏、标签；保存每首曲目的音轨和练习速度 |
| 原曲伴奏 | WAV 波形、两点对齐、独立音量；随谱面播放、暂停、跳转和循环 |
| 指板训练 | 目标弦品显示、音名/音程切换；12 个根音的音阶与和弦练习 |
| 练习工具 | 调音器、鼓机、节拍器、速度阶梯、干声录音及效果链回放、练习统计 |

## 系统要求

- Windows 10 / 11，64 位。
- 实时弹奏建议使用带 Hi-Z / INST 输入的 USB 声卡及厂商 ASIO 驱动。
- 编译时静态链接 MSVC 运行库；便携版解压即可运行。
- NAM、IR 和 VST3 为可选功能，模型、音色资源和插件需要自行准备。

## 安装与开始使用

1. 在 [Releases](https://github.com/Gx-20hh/GGitar/releases) 中下载 `GGitar-版本-windows-x64.zip`。
2. 解压整个文件夹，运行 `GGitar.exe`。
3. 将吉他连接到声卡的 Hi-Z / INST 输入，耳机连接到声卡。
4. 打开“音频设置”，选择设备、输入通道、采样率和缓冲区。建议从 48 kHz、128 samples 开始调整。
5. 在效果器页调整音色，或进入练习页打开吉他谱。

若听到双重监听声，请关闭声卡的 Direct Monitor；发生爆音时，可增大缓冲区。

### 曲库与跟弹

在“我的曲库”中扫描存放 GP 文件的文件夹。可搜索曲名、歌手和标签，双击曲目开始练习。收藏和标签保存在本机；移出曲库不会删除原文件。

“谱面跟弹”支持选择音轨、调节速度、设置 A–B 循环和开启等待模式。使用弹奏判定前，建议先完成延迟校准。

### 原曲伴奏

先打开谱子，再在“原曲伴奏”导入 WAV。点击波形选中音频时间点，将谱面定位到对应位置，点击“对齐第一点”。在较远的位置设置第二点，可修正整体时间比例。

原曲与谱面共用播放位置，可独立静音及调节音量。当前采用随速变调播放，尚未提供原曲保调变速。

### 指板训练

“跟随当前谱面”显示所选音轨的目标弦品。也可选择根音与训练类型，设置 BPM 后生成练习：大调音阶、自然小调音阶、小调五声音阶、大三和弦和小三和弦，共 60 种组合。

## 常用快捷键

| 按键 | 操作 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| ← / → | 上一 / 下一小节 |
| Home | 返回开头 |
| A / B | 设置循环起点 / 终点 |
| ↑ / ↓ | 调节速度 |
| W | 切换等待模式 |
| N | 切换谱面音名 |

快捷键用于练习页；编辑输入框时以输入框操作为准。

## 数据与资源

- 设置、曲库索引和练习记录：`%APPDATA%\GGitar\`
- 音色预设、录音和用户谱库：`文档\GGitar\`
- 可选模型和脉冲响应：程序旁的 `音色库\NAM`、`音色库\IR`

文件扫描和练习数据在本机处理。在线找谱会打开外部网站。移动原始谱子或 WAV 后，需要重新扫描或导入。

发布包不包含个人设置、录音、用户谱库或第三方商业插件。本仓库未附带 NAM 模型、IR 和 Gervana 图片；不依赖这些资源的内置效果器仍可使用。

## 当前限制

- 原曲伴奏目前仅支持 WAV；变速会变调。两点对齐不能自动校正自由速度演奏中的局部变化。
- 单个 WAV 的解码后立体声缓存上限为 256 MiB。
- 指板显示谱面目标位置，不代表识别实际手指位置，也不能区分同音异弦。
- 内置训练采用标准六弦调弦；生成的训练谱暂不自动加入曲库或练习历史。
- 声卡、ASIO 驱动和 VST3 插件兼容性需要在具体设备上验证。

## 从源码构建

安装 Visual Studio 2022 或更新版本，选择“使用 C++ 的桌面开发”，并安装 Windows SDK 和 CMake 工具。

- **构建程序**：运行 `build.bat`，成功后生成 `GGitar.exe`。
- **生成发布包**：运行 `package.bat`，产物位于 `发布\`。
- **自动构建**：仓库的 Windows Release 工作流负责构建、测试、打包和发布。

JUCE 和 NAM 核心依赖已包含在 `third_party/` 压缩包中。手动使用 CMake 前，需分别解压为 `third_party/JUCE/` 和 `third_party/nam/`。

```powershell
cmake -S . -B build -A x64 -DGGITAR_BUILD_TESTS=ON
cmake --build build --config Release --target GGitar GGitarFeatureTests --parallel 2
ctest --test-dir build -C Release --output-on-failure
```
