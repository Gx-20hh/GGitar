# 老干部活动中心

制作者：痛风老大爷

电吉他接声卡，实时监听、自由组装效果器链、跟着鼓机练琴，打开吉他谱像音游一样跟着弹。

## 现在有的功能

**接声卡（第一阶段）**
- 选声卡驱动（优先 ASIO，也支持 WASAPI / DirectSound）、设备、采样率、缓冲区
- 选吉他所在的输入通道；输入增益、吉他音量、监听开关
- 输入 / 输出电平表（带削波 CLIP 灯），往返延迟和 CPU 占用
- 调音器（读取未处理的干信号）

**效果器链（第二阶段）**
- 22 种内置效果器：
  - 动态：降噪（可去 50/60 Hz 嗡声）、噪声门、压缩、音量
  - 失真：过载、失真、法兹
  - 箱头 / 箱体：音箱模拟、箱体模拟（1x12 / 2x12 / 4x12，给只有箱头的 NAM 模型用）
  - 音色：均衡、图示均衡（7 段）、哇音（手动 / 跟随力度 / 循环）
  - 音高：八度（复音可弹和弦 / 单音模拟）、移调 / 和声（±12 半音）
  - 调制：合唱（立体声）、镶边、相位、颤音、揉音
  - 空间：延迟、混响（房间 / 大厅 / 板式）、空灵混响
- **经典型号**（数字模拟，不需要模型文件）：
  - 音箱模拟的“型号”：美式清音 Twin 风格、美式黑面 Deluxe 风格、英式 Plexi 风格、英式 JCM800 风格、英式 AC30 风格、
    Mesa Mark 风格、Mesa 双整流风格、5150 风格（增益结构、音色堆栈、功放余量 / 下沉、喇叭箱都按各自的特点调）
  - 过载的“型号”：TS808 风格、TS9 风格、人马 Klon 风格、SD-1 风格、Blues Breaker 风格
  - 失真的“型号”：RAT 风格、DS-1 风格
  - 预设栏里新增 10 个“经典 ·”预设，和 8 个用自带 NAM 真实采样的“真实采样 ·”预设（5150、Mesa Mark IV、Twin、JCM2000、JVM、AC15、OD808、Klon 克隆）
- **NAM 箱头**：加载 `.nam` 模型文件（Neural Amp Modeler，网上有大量免费的真实箱头模型）
- **箱体 IR**：加载 `.wav` 脉冲响应
- **VST3 插件**：扫描并加载电脑上已安装的 VST3 效果器，打开插件自己的界面
- 单块操作：单击脚踩开关 = 开 / 关；**双击 = 弹出放大的踏板**，所有旋钮、开关、选择器都在上面
  （拖动旋钮调节，双击旋钮恢复默认，点空白处或按 Esc 关闭）；拖动 = 调整顺序；右键 = 更换模型、复制、删除等
- 不同品类用经典踏板的颜色：过载绿、失真橙、法兹红、压缩蓝、合唱浅蓝、八度黄、延迟白、混响深蓝、哇音黑、均衡银……
- 延迟和颤音可以“同步鼓机”，按鼓机速度自动算时间（1/4、附点 1/8、1/8、三连音、1/16）
- 改链路、开关效果器时自动淡入淡出，不会爆音
- **音色预设**：整条链存成文件，自带 4 个默认音色（清音、过载、高增益、Solo 延迟）
  预设文件夹：`我的文档\LianqinHost\音色预设`

**鼓机（第二阶段）**
- 12 种风格：摇滚、流行、慢歌、放克、迪斯科、朋克、金属、蓝调 Shuffle、雷鬼、爵士 Swing、华尔兹 3/4、仅节拍器
- 每种风格有主歌 / 副歌两种节奏型，外加加花（可每 2 / 4 / 8 小节自动加花，也可以手动点“加花”）
- 速度 30–300 BPM、点击“打拍”自动测速、摇摆感、预备拍、叠加节拍器
- 鼓声是实时合成的，不需要采样文件；鼓声不经过吉他效果器
- **空格键**开始 / 停止

**练习谱面（第三阶段）**
- 打开 Guitar Pro 3 / 4 / 5 / 6 / 7 / 8 谱子（`.gp3 .gp4 .gp5 .gpx .gp`），也可以直接拖进窗口
- **在线找谱**：点“在线找谱…”输入歌名，一键在吉他社 / Songsterr / Ultimate Guitar / 必应里搜索（浏览器打开）；
  在网页上下载 GP 文件后，程序发现“下载”文件夹里多了谱子，会自动拷进 `吉他谱\` 并打开（等 20 分钟，可随时“停止等待”）。
  浏览器下载到别处的话，在搜索框里“换文件夹…”
- 自动展开反复记号、跳房子（1. 2. 结尾），连音线合并，读取变速
- **音游式谱面**：每根弦一条彩色轨道（上面是 1 弦），音符带品位数字从右往左滚到判定线；
  每个音上面写着音名（例如 E4、C#3，可以用“音名”开关或 N 键关掉）；
  延音拖尾、和弦连线、小节号、段落标记；技巧标记：H 击弦、P 勾弦、PM 闷音、× 死音、◇ 泛音、斜线滑音、↑ 推弦（拖尾会弯上去）、波浪线揉弦
- **示范音**：用拨弦合成器播放你选的那一轨（可以关掉自己弹），其他轨当伴奏，谱里的鼓轨用鼓机的鼓声
- **全部音轨合奏**：音轨下拉菜单最上面的“全部音轨（合奏）”，所有音轨一起播放（只听，不判定）
- **混音…**：每条音轨单独调音量、静音（M）、独奏（S），比如只留鼓和贝斯陪你练
- **变速**：25%–150%，不变调
- **A-B 循环**：按 A / B 设当前小节为起点 / 终点，或者在底部进度条上直接拖动框选（自动对齐小节）
- 预备拍（一小节）、节拍器；延迟 / 颤音“同步鼓机”时跟着谱子的速度走
- 快捷键：空格 播放/暂停、← → 上/下一小节、Home 回到开头、A / B 循环点、↑ ↓ 调速度、W 等待模式、N 音名
- 记住上次打开的谱子和音轨；“最近 ▾”里有最近 12 个文件

**弹奏判定（第四阶段）**
- 听你弹的**干信号**（效果器之前，失真不影响判定），实时判断每个音：**Perfect**（±40 ms）、**Good**（±150 ms）、**错音**、**Miss**
- 只核对“谱上该出现的音在不在”，所以单音、和弦都能判；击弦 / 勾弦 / 滑音的目标音不用拨弦，到时间直接核对音高；
  推弦、泛音、闷音只判时间。分不出同一个音在哪根弦上弹，所以不判弦
- 谱面上：判过的音带彩色边框（金 Perfect、绿 Good、橙 错音、红叉 Miss），判定线上飘字并显示早 / 晚多少毫秒；
  右上角计分板（命中率、连击、各项数量、循环时上一遍的成绩）；进度条上沿按小节显示命中率色带
- **等待模式**（快捷键 W）：弹对了谱子才往下走，弹错会提示“错音”，可以重弹
- A-B 循环每一遍重新计分；弹完整首出**成绩卡**：命中率、整体偏早 / 偏晚、最需要练的 3 个小节（点一下就循环练那一节）
- **延迟校准**：跟着节拍器弹 16 下，自动测出声卡报告之外的额外延迟，以后判定自动扣掉
- 谱面间距改成在谱面上**滚鼠标滚轮**调

**练习工具（第五阶段）**
- **录音 / 回放**：“● 录音”把你弹的干信号（效果器之前）录成 WAV，存在 `我的文档\LianqinHost\录音`；
  “回放…”把录音当成吉他输入重新走现在的效果器链，可以边听边换音色。先按录音再按播放的话，
  回放时谱子、伴奏、判定会从同一拍对上（等待模式下录的只回放声音）
- **速度阶梯**：速度旁边的“阶梯…”。在 A-B 循环里从起始速度开始，连续过够几遍（开着判定时命中率还要达标）就自动提一档，到目标速度停
- **练习记录**：顶部第三个页签。今天 / 最近 7 天 / 连续天数 / 累计练习时间，最近 14 天每天练了多久，
  每首歌的累计时间、原速最好成绩，选中一首看每一遍的命中率和当时的速度；“去练这首”直接打开。
  记录存在 `%APPDATA%\LianqinHost\练习记录.json`

## 编译

1. 安装 **Visual Studio 2022 或更新版本**（Community 版即可），勾选 **“使用 C++ 的桌面开发”**，
   并确认“单个组件”里装了 **Windows 11 SDK**。
2. 双击 **`build.bat`**。第一次编译约 5–15 分钟（NAM 库比较大）。
3. 编译成功后双击 **`LianqinHost.exe`**。
4. 想发给别人：双击 **`package.bat`**，在 `发布\` 里生成 `老干部活动中心-v版本.zip`
   （程序 + 音色库 + 使用说明 + 许可证 + 源码.zip）。对方解压就能用，不用装 VC++ 运行库。

JUCE 9.0.4 和 NAM 核心库都已打包在 `third_party/` 里，编译时不用联网。

## 使用

### 第一次连接声卡
1. 吉他接声卡的 **Hi-Z / INST** 输入口，耳机接声卡。
2. 点右上角 **“音频设置…”**：类型选 **ASIO**，勾选吉他那一路输入，缓冲区选 **64** 或 **128**。
3. 左栏“吉他输入通道”选那一路。用力扫弦时输入电平到 -12 ~ -6 dB 比较合适，CLIP 灯亮就把声卡增益调小。

### 用 NAM 箱头
1. 去 [TONE3000](https://www.tone3000.com)（原 ToneHunt）下载 `.nam` 模型和箱体 IR。
2. 效果器链末尾点 **“+ 添加效果” → 加载 NAM 箱头模型…**
3. 大多数 NAM 模型只包含箱头，后面再加一块 **箱体 IR**；如果模型名里写了 “full rig” 或带 cab，就不用再加 IR。
4. NAM 模型一般要求 **48 kHz** 采样率，单块上出现橙色“需要 48.0 kHz”提示时，在音频设置里把采样率改成 48000。
5. 用 NAM 时可以把内置“音箱模拟”关掉或删掉。

### 用 VST3 插件
1. **“+ 添加效果” → 管理 / 扫描 VST3 插件…**
2. 在弹出的窗口左下角点 **Options → Scan for new or updated VST3 plug-ins**。
   默认扫描 `C:\Program Files\Common Files\VST3`。
3. 扫描完，插件会出现在 **“+ 添加效果” → VST3 插件** 菜单里。

如果某个插件扫描时让程序崩溃，重新打开后再扫描会自动跳过它。

### 音色库
程序旁边的 `音色库\NAM`、`音色库\IR` 是选模型时默认打开的文件夹。预设里引用这里面的文件时存的是相对路径，
整个文件夹拷到别的电脑上（或者打包发给别人）照样能找到模型。

### 效果器推荐顺序

降噪 → 压缩 → 哇音 → 八度 / 移调 → 过载 / 失真 / 法兹 → 箱头（音箱模拟或 NAM）→ 箱体（箱体模拟或 IR）
→ 均衡 → 合唱 / 镶边 / 相位 / 颤音 → 延迟 → 混响

降噪最好放在最前面；八度和移调放在失真前面跟踪更准，放后面声音更“合成器”。
复音八度 / 移调能弹和弦，三和弦里的三度音会稍微有点糊，强力和弦和单音最干净。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 听到两份吉他声、有回音 | 关掉声卡的“直接监听 / Direct Monitor” |
| 有爆音、噼啪声 | 缓冲区调大一档（64 → 128 → 256） |
| CPU 占用高 | NAM 和部分 VST3 插件比较吃 CPU；缓冲区调大，或者少开几块 |
| 鼓声太大 / 太小 | 鼓机面板的“鼓音量”；吉他用左栏的“吉他音量” |
| 设备类型里没有 ASIO | 安装声卡官方驱动，应急可以用 ASIO4ALL 或 FlexASIO |

设置保存在 `%APPDATA%\LianqinHost\LianqinHost.settings`，删掉它可以恢复默认。
