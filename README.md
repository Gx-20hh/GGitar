# GGitar

电吉他练习工作台。连接声卡、调整音色、导入吉他谱，集中完成日常练习。

项目维护：[Gx-20hh](https://github.com/Gx-20hh) · Windows 10 / 11 x64 · 当前源码版本：0.3.0

## 功能

| 模块 | 内容 |
| --- | --- |
| 声卡接入 | ASIO、WASAPI、DirectSound；输入通道、增益、监听、电平和调音器 |
| 音色处理 | 内置效果器链、NAM 箱头模型、箱体 IR、VST3 插件及音色预设 |
| 鼓机 | 多种节奏风格、速度、加花、摇摆和节拍器 |
| 跟谱练习 | Guitar Pro 文件导入、滚动谱面、多轨播放、混音、变速和 A–B 循环 |
| 训练反馈 | 音符判定、等待模式、延迟校准和练习成绩 |
| 练习管理 | 干声录音、回放、速度阶梯和练习记录 |

支持导入 `.gp3`、`.gp4`、`.gp5`、`.gpx`、`.gp`。不同曲谱的技巧与播放效果以实际导入结果为准。弹奏判定作为练习参考，不能区分同一音高实际使用的弦位。

## 开始练习

1. 吉他连接声卡的 **Hi-Z / INST** 输入，耳机连接声卡输出。
2. 打开 **音频设置**，选择设备、输入通道、采样率和缓冲区。优先使用声卡厂商的 ASIO 驱动。
3. 拨弦检查输入电平，避免削波。出现爆音时增大缓冲区。
4. 选择音色，或添加 NAM、IR、VST3 效果器。
5. 在 **练习谱面** 中打开吉他谱，选择音轨、速度和循环范围。
6. 使用判定前进行延迟校准；通过录音回放检查弹奏。

使用软件监听时，按需关闭声卡直接监听，避免双重声音。

## 构建与打包

安装 Visual Studio 2022 或更新版本，勾选“使用 C++ 的桌面开发”和 Windows SDK，然后运行：

```bat
build.bat
```

构建成功后运行 `GGitar.exe`。执行 `package.bat`，将在 `发布` 文件夹生成 `GGitar-v0.3.0.zip`。实际版本号读取自 `CMakeLists.txt`。

仓库包含 JUCE 和 NAM 核心库压缩包。NAM 模型、箱体 IR、踏板图片和商业 VST3 插件需自行准备；请检查文件各自的使用许可。预设引用外部模型时，需要相应文件才能得到完整音色。

## 数据位置

为兼容已有设置，内部数据目录继续使用 `LianqinHost`：

- `%APPDATA%\LianqinHost\`：设备设置、练习记录。
- `我的文档\LianqinHost\`：音色预设、录音和用户曲谱。
- 程序目录下的 `音色库\`：NAM、IR 等外部资源。

更换电脑时可备份上述用户数据目录。设备和插件路径需要在新电脑重新确认。

## 常见问题

| 问题 | 检查项 |
| --- | --- |
| 没有输入信号 | 声卡输入、软件通道、增益和设备占用 |
| 爆音或卡顿 | 增大缓冲区，减少高负载效果器 |
| 听到双重声音 | 检查硬件直接监听与软件监听是否同时开启 |
| NAM 模型无法正常使用 | 检查模型文件和采样率要求 |
| 谱面判定偏早或偏晚 | 重新校准，并检查当前音频配置 |
