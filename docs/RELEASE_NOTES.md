GGitar 0.4.0 — Windows 电吉他练习工作台。

### 新增功能
- 本地曲库：扫描、搜索、收藏、标签与每曲练习设置。
- WAV 原曲伴奏：波形、两点对齐及谱面同步播放。
- 动态指板与 60 种音阶/和弦练习。

### 下载
- `windows-x64.zip`：便携版，完整解压后运行 `GGitar.exe`。
- `source.zip`：对应源码与构建依赖。
- `SHA256SUMS.txt`：下载文件校验值。

### 已知限制
原曲仅支持 WAV，变速会变调；不附带 NAM 模型、IR、Gervana 图片或商业 VST3 插件。内置训练谱暂不写入曲库/历史。声卡与 ASIO 驱动仍需在实际硬件上验证。程序未进行代码签名。
